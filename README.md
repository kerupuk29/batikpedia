# BatikPedia - Aplikasi Edukasi Interaktif Batik Nusantara

Proyek sistem multimedia berupa aplikasi desktop interaktif untuk mengedukasi masyarakat mengenai berbagai motif batik khas Jawa Barat beserta makna filosofisnya.

## ⚙️ Persiapan (Prerequisites)
Sebelum menjalankan aplikasi ini, pastikan komputer Anda sudah ter-install:
- **Node.js** (Versi LTS) - [Download di sini](https://nodejs.org/)
- **Git** - [Download di sini](https://git-scm.com/)

## 🚀 Cara Instalasi & Menjalankan Aplikasi
Ikuti langkah-langkah berikut untuk menjalankan BatikPedia di komputer Anda:

1. **Clone Repository ini**
   Buka Terminal / Command Prompt, lalu ketik:
   ```bash
   git clone [https://github.com/kerupuk29/batikpedia.git](https://github.com/kerupuk29/batikpedia.git)
2. Masuk ke Folder Proyek
   Buka folder hasil clone tersebut di Visual Studio Code.
3. Install Dependencies (Mesin Penggerak)
   Buka Terminal di dalam VS Code (pilih Command Prompt), lalu ketik perintah ini dan tekan Enter:
   npm install
  (Catatan: Perintah ini akan otomatis mendownload Electron.js dan semua kebutuhan lainnya yang terdaftar di package.json)
4. Jalankan Aplikasi
   Setelah proses install selesai, ketik perintah ini untuk membuka aplikasinya:
   npm start
